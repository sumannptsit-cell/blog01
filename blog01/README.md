
# Blog01

A simple blog application built using Node.js, Express.js and EJS.

## Features

- Create new blog posts
- View individual blog posts
- Edit existing posts
- Delete blog posts
- Input validation
- Display post creation and editing dates

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- EJS

## Installation

1. Clone this repository.
2. Open the project folder in VS Code.
3. Install the dependencies:

```bash
npm install
```

4. Start the server:

```bash
node index.js
```

5. Open your browser:

http://localhost:5000
